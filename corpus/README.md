# Демонстрационный корпус «Контур»

Все девять тематических документов написаны специально для этого проекта на русском языке. «Контур», его организация, процедуры, ситуации и численные примеры вымышлены; внешние материалы не заимствованы. Корпус предназначен для проверки локального поиска, ссылок на разделы и диалога с RAG, а не для применения его инструкций к реальному оборудованию. Документы охватывают требования к сервису, приём файлов, поисковые стратегии, развёртывание, инциденты, управление знаниями, испытания, согласованное хранение и практические сценарии.

## Подтверждение объёма

Подсчёт выполнен по исходным девяти Markdown-документам `01_*.md` … `09_*.md` в кодировке UTF-8. Словом считается непрерывная последовательность букв или цифр (Unicode), с возможным внутрисловным дефисом `-` или `‑`; разделители Markdown сами по себе не считаются. Отдельно подсчитаны русские словоформы, содержащие кириллические буквы, по правилу `[А-Яа-яЁё]+(?:[-‑][А-Яа-яЁё]+)*`. Заголовки документов и разделов включены, этот README и `questions.json` исключены.

| --- | ---: | ---: |

| `02_ingestion.md` | 1 234 | 1 225 |
| `03_search.md` | 1 261 | 1 246 |

| **Итого** | **11 145** | **10 984** |

При прозрачной оценке **500 слов ≈ 1 страница** общий объём составляет **22,29 условной страницы**; одних русских словоформ достаточно для **21,97 условной страницы**. Это оценка текстовых файлов, а не число физических страниц PDF. Подсчёт можно воспроизвести следующим фрагментом Python 3.11+ из корня проекта:

```python
from pathlib import Path
import re

files = sorted(Path("corpus").glob("[0-9][0-9]_*.md"))
words = re.compile(r"(?<!\w)[^\W_]+(?:[-‑][^\W_]+)*(?!\w)")
russian = re.compile(r"[А-Яа-яЁё]+(?:[-‑][А-Яа-яЁё]+)*")
for file in files:
    text = file.read_text(encoding="utf-8")
    print(file.name, len(words.findall(text)), len(russian.findall(text)))
```

## Контрольные вопросы

`questions.json` содержит 18 вопросов с ожидаемым именем файла в поле `source` и точным названием заголовка в поле `section`. Имена файлов заданы относительно этой папки. Эти эталоны подходят для сравнения попадания источника в первые пять результатов двух стратегий; они не являются эталонными готовыми ответами языковой модели и не доказывают фактическую правильность генерации. Если содержание или заголовок документа меняется, вопрос и ожидаемый раздел нужно пересмотреть вместе с редакцией корпуса.
